# Javions

Projet Java du cours CS-108 (EPFL) : décodage des messages ADS-B émis par les avions.

## Structure

```
src/        code source (ch.epfl.javions)
  aircraft/       base de données des aéronefs
  adsb/           messages ADS-B
  demodulation/   démodulation du signal radio
test/       tests JUnit 5
resources/  données (aircraft.zip)
```

## Prérequis

- JDK 17
- JUnit 5 (Jupiter)

Ouvrir le dossier dans IntelliJ IDEA (module `Javions.iml`).
